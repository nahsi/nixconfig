# Investigation playbook

Use for read-only “how,” “why,” ownership, placement, history, and impact questions.

1. State the precise question and which decision the answer should enable.
2. Run [`context-map`](skill://context-map) in `how`, `why`, or `change impact` mode.
3. For broad work, use [`prime-delegate`](skill://prime-delegate) fan-out by independent evidence source or boundary. Children remain read-only and reply with citations.
4. Distinguish observed evidence, inference, and unknowns.
5. Verify disputed/load-bearing claims directly in the root.
6. Synthesize the smallest useful map; do not dump all explored files or child prose.
7. Do not edit code unless the user separately asks for implementation.

If the investigation exposes a decision, transition to [`shape-work`](skill://shape-work); if it exposes executable work, transition to [`verticalize-work`](skill://verticalize-work).
